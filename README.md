# tools

A collection of browser-based utilities, hosted at **https://fvlb.github.io**

## Tools

### 🔧 [HEX File Merger](https://fvlb.github.io/hex_merger/)
Merge up to 4 Intel HEX / BIN files into a single binary or HEX output.
- Drag-and-drop or browse for `.hex` / `.bin` files
- Visual memory map with overlap detection
- Configurable filler byte, output filename, and BIN trim option
- Export as `.bin` or Intel HEX (with optional STM32 base address)

### 📁 [Folder Word Counter](https://fvlb.github.io/words_count/)
Browse a folder and count words across e-book files (fb2, epub, txt, docx…).

### 🔌 [WebUSB LED & Button Demo](https://fvlb.github.io/webusb-led/)
Control LED brightness and watch button-press events live from the browser
via WebUSB, no drivers needed. Works with the CH32L103 and CH592F WinUSB/
WebUSB demo firmware (https://github.com/fvlb/ch32l103_ch592f_web_usb).

---

> All tools run entirely in the browser — no server, no uploads.
